# Hotel Customer Experience Analytics Portfolio Project

A portfolio-ready customer experience analytics project for a hotel business, designed to demonstrate practical skills in Excel, SQL-style analysis, KPI reporting, customer segmentation, root-cause analysis, and actionable recommendations.

## Business Objective

Understand what drives hotel customer satisfaction, identify the largest CX pain points, and recommend operational improvements that can increase guest satisfaction and reduce negative experiences.

## Project Scope

- Guest experience and satisfaction analysis
- Review and complaint theme analysis
- Service quality KPI tracking
- Segment analysis by guest type, room type, booking channel, and stay characteristics
- Root-cause identification
- Executive recommendations

## Core KPIs

| KPI | Purpose |
|---|---|
| Overall Satisfaction Score | Measures guest experience quality |
| Complaint Rate | Tracks frequency of reported service issues |
| Recommendation Rate | Indicates likelihood of guests recommending the hotel |
| Repeat Guest Rate | Measures customer retention |
| Average Rating | Tracks review performance |
| Response / Resolution Rate | Measures service recovery effectiveness |

## Portfolio Deliverables

- `data/` for the analysis dataset
- `analysis/` for calculations and SQL-style analysis
- `dashboard/` for KPI dashboard screenshots and outputs
- `case-study/` for the professional case study PDF and presentation assets
- `recommendations/` for the final action plan

## Important Note

This is a portfolio case study using a simulated hotel CX dataset created for learning and demonstration. It does not represent actual hotel company performance.
